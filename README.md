# 온라인 교육 서비스 사용자 이탈 분석
> 이탈 행동 분석을 통한 콘텐츠 시작 전환 개선안 설계

🔗 [Tableau 대시보드 바로가기](https://public.tableau.com/app/profile/jiwoo.lee8788/viz/_17788274740880/sheet0#)

## 개요
- 목표: 이탈 지점을 파악하고 리뷰 노출 개선을 통해 콘텐츠 시작 전환 높이기
- 기간: 2026.04.20 ~ 2026.05.18
- 팀: 데이터 분석가 5명
- 데이터: 2022.01 ~ 2023.12 (2년)
- 분석 방법: 퍼널 분석 · 이탈 시점 세그먼트 분석 · A/B 테스트 설계

## 분석 과정
1. AARRR 퍼널 분석 (5단계)
2. 이탈 시점별 행동 분석
3. A/B 테스트 설계 (그룹당 2,735명 / 총 5,470명, 약 39일)
   - 리뷰 정렬: A 최신순 / B 추천수 기준 베스트순
   - 성공 지표: 리뷰 더보기 클릭 사용자의 콘텐츠 시작 전환율 (6.54% → 8.54%)
   - 양측 Z검정 · 유의수준 5% · 검정력 80%

## 주요 발견
- 가입자 144,957명 중 63.7%(92,352명)가 콘텐츠를 시작하지 않음
- 가입 후 5분 이내 이탈자의 마지막 행동: 레슨 페이지 진입 38%, 결제 페이지 진입 32%
- 가입 후 30일 이후 이탈자 중 68%가 리뷰 확인 직후 이탈

## 기대 효과
- 월 추가 콘텐츠 시작 +86명 → 월 추가 구독자 +8명 → 월 추가 매출 약 12.7만 원 (연 약 153만 원)
- 실험을 실행하지 않아, 2023년 하반기 월 평균 리뷰 방문자(4,300명)에 목표치 +2%p를 적용해 추정
