# 온라인 교육 서비스 이탈 분석

🔗 [Tableau 대시보드 바로가기](https://public.tableau.com/app/profile/jiwoo.lee8788/viz/_17788274740880/sheet0#)

## 개요
- 목표: 이탈 지점을 파악하고 리뷰 노출 개선을 통해 콘텐츠 시작 전환 높이기
- 기간: 2026.04.20 ~ 2026.05.18
- 팀: 데이터 분석가 5명
- 데이터: 2022.01 ~ 2023.12 (2년)
- 문제: 가입자 144,957명 중 63.7%(92,352명)가 콘텐츠를 시작하지 않음

## 내 역할
- 팀원 간 퍼널 수치 차이의 원인(기간·날짜 기준 등)을 찾아 기준 통일, 쿼리 공유 방식 제안
- 분석 단계별 결과 문서화 제안 및 양식 작성

## 분석 과정
1. AARRR 퍼널 분석 (5단계)
2. 이탈 시점별 행동 분석 (가입 후 5분 이내 / 30일 이후)
3. A/B 테스트 설계 (표본 2,735명/그룹, 총 5,470명, 약 39일 · 리뷰 최신순 vs 추천수 기준 베스트순)
4. 기대 효과 추정: 월 추가 콘텐츠 시작 +86명 → 구독 +8명 → 매출 약 12.7만 원 (실험 미실행, 목표치 기준)

## 주요 발견
- 가입 후 30일 이후 이탈자 중 68%가 리뷰 확인 직후 이탈

## 사용 기술
- MySQL, Python (Pandas), Tableau
